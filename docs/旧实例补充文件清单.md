## 2. 真正运行时，必须迁移的目录

| 必需内容 | 旧实例默认路径 | 迁移要求 |
|---|---|---|
| **完整自训权重** | `best.json` 的 `path` 指向的目录 | 全部 `.safetensors` 分片、索引、配置、统计量和来源记录一起迁移，不能只拿一个分片 |
| **已安装的模型/仿真环境** | `/mnt/workspace/venvs/robotwin-env/` | 保留链接与目录结构；确认其基础解释器、系统 PyTorch/ROCm 和系统动态库在相同镜像中仍存在 |
| **实际使用的 LingBot 源码** | `/mnt/workspace/src/lingbot-vla-v2/` | 必须是旧实例修改后的版本，不能用本机原始 ZIP 代替已应用补丁 |
| **实际使用的 RoboTwin 源码** | `/mnt/workspace/src/RoboTwin/` | 包括环境、任务配置、脚本、指令、机器人配置等 |
| **XPolicyLab 和本地依赖** | `/mnt/workspace/src/RoboTwin/XPolicyLab/`，以及 `/mnt/workspace/src/` 内实际被环境引用的其他目录 | 包括 editable 安装、`.pth` 或符号链接指向的实际源目录；不确定时先保存整个 `/mnt/workspace/src` |
| **Qwen 配置和 tokenizer** | `/mnt/workspace/models/Qwen3-VL-4B-Instruct-config-tokenizer/` | 整个目录，包括 processor、tokenizer、词表等；不需要另搬一套完整 Qwen 模型权重 |
| **best 选择记录** | 上述 `PARENT_RUN/best.json` | 首次 prepare 时需要，保留原内容和原路径关系 |

如果 best 指向另一个运行目录，迁移**被引用的完整导出**。纯评测不必迁移该运行的所有历史 checkpoint 或优化器状态。

`prepare` 成功后，选中模型会保存在评测批次的 `model/` 中。后续换实例带这份快照即可，不再依赖原训练运行目录。

## 3. 仿真资产：旧实例有则搬，没有则下载

确认以下目录是否存在且有实际文件：

```text
/mnt/workspace/src/RoboTwin/assets/objects/
/mnt/workspace/src/RoboTwin/assets/embodiments/
/mnt/workspace/src/RoboTwin/assets/background_texture/
```

已有则迁移；如果是软链接，要同时迁移链接目标。只有空目录、下载脚本或 Git 源码不算资产齐全。旧实例没有这些资产时，在新实例按主手册下载固定版本的三个资产包即可。

CPU 软件 Vulkan 相关系统包应在新实例按镜像和版本恢复，不直接复制整个 `/usr/lib`。基础离屏图像成功不代表 RoboTwin 真实相机和物理任务已经通过。

## 4. 建议同时保存的环境记录

在旧实例中执行以下有限信息收集，不导出完整环境变量：

```bash
mkdir -p /mnt/workspace/migration_record
/mnt/workspace/venvs/robotwin-env/bin/python -m pip list --format=json \
  > /mnt/workspace/migration_record/robotwin_packages.json
cat /etc/os-release > /mnt/workspace/migration_record/os-release.txt
readlink -f /mnt/workspace/venvs/robotwin-env/bin/python \
  > /mnt/workspace/migration_record/python_base_path.txt
/mnt/workspace/venvs/robotwin-env/bin/python -c \
  "import sys,torch; print('executable:',sys.executable); print('base_prefix:',sys.base_prefix); print('torch:',torch.__version__); print('ROCm:',torch.version.hip)" \
  > /mnt/workspace/migration_record/python_gpu_versions.txt
dpkg-query -W libvulkan1 vulkan-tools mesa-vulkan-drivers \
  > /mnt/workspace/migration_record/vulkan_packages.txt
```

把平台中的**精确镜像 ID**另写入 `migration_record/image_id.txt`。保留与该环境有关的安装记录和源码补丁；不要把 `env`、登录 Cookie、访问令牌等全量导出。

## 5. 一旦开始评测，后续最重要的续跑文件

默认评测批次目录：

```text
/mnt/workspace/runtime/robotwin_eval/clean50_best_20261015/
```

以后每次换实例都带上**整个目录**，包括：

```text
manifest.json       冻结的 500 项清单、输入身份和批次 ID
selection.json      原始 best 选择记录
model/              固定的完整模型快照
results/            已提交的逐 episode 正式结果
sessions/           每轮会话、逐次尝试日志、审计和上游原始结果
report.json         可重建的累计汇总
report.md           可重建的人类可读报告
```

报告不是续跑的唯一依据。只有 report.json、成功率截图或控制台输出，不能可靠恢复。应停止旧调度器并确认子进程退出后再备份，不能让两台实例同时运行同一批次的两个副本。
