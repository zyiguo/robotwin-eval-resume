# 从独立 GitHub 仓库运行本地软件测试

本仓库保留原项目的 `01_工程`、`02_运行归档` 和 `docs` 布局，使评测工具与已验收版本一致。工具包可以直接使用；若要在新 checkout 重跑测试或重新打包，需要额外下载三个公开固定版本源码 ZIP 作为测试输入。它们不是旧实例的环境备份，不包含云端实际修改过的源码。

## 下载固定测试输入

在仓库根目录执行。Windows PowerShell 使用 here-string，不使用 Bash heredoc：

```powershell
@'
import json
from pathlib import Path
from urllib.request import urlretrieve

root = Path('02_运行归档/源码备份')
records = json.loads((root / 'sources.json').read_text(encoding='utf-8'))
needed = {'RoboTwin', 'lingbot-vla-v2', 'Robotwin-radeon-cloud'}
for row in records:
    if row['name'] not in needed:
        continue
    out = root / (row['name'] + '.zip')
    if out.exists():
        print('KEEP', out)
        continue
    repo = row['url'].removesuffix('.git').split('github.com/', 1)[1]
    url = 'https://codeload.github.com/' + repo + '/zip/' + row['commit']
    pending = out.with_suffix('.pending.zip')
    print('DOWNLOAD', url)
    urlretrieve(url, pending)
    from zipfile import ZipFile
    with ZipFile(pending) as archive:
        assert archive.testzip() is None
    pending.rename(out)
'@ | python -
```

Linux 可将相同 Python 代码保存到临时 `.py` 文件后执行。请保留固定 commit，不用最新分支替代。

## 依赖和命令

软件测试需要 Python 3.12、PyYAML 与 NumPy，不要求真实 GPU 或安装 SAPIEN。使用自己的隔离环境，避免改动已经跑通的云端环境。

```text
python -m pip install "PyYAML>=6,<7" "numpy==1.26.4"
python -m unittest discover -s 01_工程/tests -p test_robotwin_eval.py -v
python 01_工程/scripts/build_robotwin_eval_package.py
```
